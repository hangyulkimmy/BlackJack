# Blackjack

Multiplayer blackjack with betting — up to 3 players against the dealer, each with their own bankroll.

Built in [Code.org App Lab](https://code.org/educate/applab) as a final project. Everything the game does is in `code.js`; the UI is App Lab's design-tab HTML.

<!-- screenshot: docs/table.png -->

## Features

- 52-card shuffled deck, real card art
- Hit / stand per player, dealer plays out automatically
- Aces count as 1 or 11
- Betting with per-player balances
- Rules screen

## Files

```
index.html   App Lab screens & controls
code.js      all game logic
style.css    control styling
assets/      card images
applab/      App Lab runtime (needed to run standalone)
```

Open `index.html` in a browser to play.
